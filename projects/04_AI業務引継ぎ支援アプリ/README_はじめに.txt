HANDOVER LAB｜第4作 AI業務引継ぎ支援アプリ
==================================================

【最短の試し方】
1. 「04_業務引継ぎ支援アプリ.html」をダブルクリックして開く。
   Windows上のChrome / Edgeなどで動く、ローカルHTML形式。
2. 「架空の業務メモを試す」を押して、「AIへの指示を作成 →」へ。
3. 本番のAI連携では、「指示全文をコピー」し、ChatGPTまたはClaudeに貼る。
   返答されたJSONをアプリへ貼り、「回答を検証して取り込む」。
4. AIを使わずにまず動作確認する場合は「デモ回答で試す」を押す。
   ※このデモ回答は事前作成された架空データで、AIとの通信は行わない。
5. 「03 引継ぎ資料を完成」で内容を編集・確認し、出力ボタンから保存。

【何ができるか】
・手書きメモを転記した文章や、音声の「書き起こしテキスト」を入力
・実際のメモを含んだAI向け指示文（JSON出力ルールを含む）を作成
・ChatGPT / Claudeから受け取ったJSONデータを形式確認して取り込む
・業務概要、作業手順、完了判定、証跡、リスク、不明点、引継ぎToDoを編集
・HTML手順書、Markdown手順書、チェックリストCSV、編集保存JSONを出力
・保存したJSONを再度読み込んで編集を再開

【本番連携の重要な区別】
このアプリ自体には生成AIモデルやAPI呼び出しは組み込まれていない。
AIの文章理解・構造化は、利用者が外部のChatGPT / Claudeへ送ったときに実行される。
入力・JSONの形式検査・編集・ファイル出力は、ブラウザ内で処理される。
「デモ回答」は完成済みの架空サンプルで、リアルタイムのAI回答ではない。

【情報セキュリティ】
・個人情報、実在顧客名、パスワード、機密資料をAIへ無断で貼り付けないこと。
・外部AIへの送信前に匿名化し、勤務先のAI利用ポリシーを確認すること。
・ブラウザ編集内容はサーバーへ送信しないが、ローカルファイルの取り扱いには注意。
・HTML手順書に記載される業務上の指示は現場担当者の確認が必要。
・CSVをExcel等で開くときの数式としての実行リスクについて、危険な先頭文字は保護している。

【対応形式・制約】
入力：直接貼付、UTF-8のTXTファイル（最大2MB）
AI応答：指定フォーマットのJSON文字列。JSONコードフェンスの有無に対応。
出力：HTML / MD / CSV（UTF-8 BOM）/ JSON。
音声ファイルそのものの自動文字起こしは未実装。
JSONの形式は検証するが、業務上の正確さやAIによる誤情報は自動判定しない。
AI回答がスキーマに合わないときは、AIへ「出力見本どおりのJSONのみで再出力」と指示。
編集内容は自動保存されないため、終了前にJSONを出力して保管すること。
CSVは「手順・ToDo・不明点」のチェックリストであり、経営数値集計用ではない。

【同梱物】
04_業務引継ぎ支援アプリ.html        ：実行する本体
04_業務メモ_架空例.txt             ：貼り付け用の架空メモ
04_デモ回答_架空例.json            ：架空の構造化結果
04_AIへの指示文_実例.txt           ：自動生成される指示文の実例
04_出力例.html                    ：手順書の保存見本
04_出力例.md                      ：Markdown保存見本
04_出力例.csv                     ：チェックリストの保存見本
04_出力例.json                    ：編集済みデータの保存見本
04_画面プレビュー.png             ：編集画面の画像
04_動作テスト結果.txt              ：Chromium自動テスト結果
04_制作・修正履歴.txt              ：AI利用と作業の記録
04_転職ポートフォリオ説明.txt      ：発表・面接での説明材料

【動作確認】
Chromiumヘッドレスブラウザで読み込みから出力まで自動テスト実施。
実機のWindowsでの操作確認、実際のChatGPT/Claudeの回答品質検証、導入先での利用は別途必要。
