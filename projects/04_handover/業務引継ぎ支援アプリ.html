01 / 前任者の業務メモを入力

TEXT OR TRANSCRIBED SPEECH
入力

口頭説明の書き起こしや箇条書きで大丈夫です。業務名・頻度・作業手順・例外対応があると精度が上がります。

0 文字

入力時の確認ポイント

  • 「いつ、誰が、何をするか」
  • 作業完了を判断する条件
  • トラブル時の連絡先・対応
  • 資料の保管場所・引継ぎの期限
機密情報に注意
AIサービスへ貼り付ける前に、個人情報・顧客情報・認証情報・社内機密を除去し、組織の利用ルールを確認してください。

このアプリがすること

プロンプトの生成、AI回答JSONの構造確認、編集と資料出力はローカルで行います。

文章の理解と手順書の生成は、利用者が選んだChatGPT/Claudeで行います。外部AIに自動送信する機能はありません。

02 / AIに渡すプロンプト

STRUCTURED EXTRACTION · NO API KEY
AI処理は外部
「① コピー → ② ChatGPTまたはClaudeに貼る → ③ 返ってきたJSONを下へ貼る」の順です。
ChatGPTを開く ↗Claudeを開く ↗
AIがJSON以外の説明文をつけた場合は、JSON部分だけを貼ってください。JSONコードブロック（```json ... ```）も取り込めます。

AIの回答を取り込む

PASTE JSON OUTPUT
JSONを取り込むと、次の画面で編集できます。デモ回答は事前作成済みの架空サンプルであり、AIへの通信は行いません。

構造化で作る情報

01業務概要
02実施手順
03リスク・注意点
04未確認事項 / ToDo

AIが入力文にない事実を補わないよう、判断できない点は「未確認」として取り出す設計です。

生成した手順は誤る可能性があります。現場の担当者が必ず確認してから利用してください。
